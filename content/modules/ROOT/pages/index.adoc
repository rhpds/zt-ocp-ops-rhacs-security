== Let's Go

You have cluster admin access to a live OpenShift cluster with Red Hat Advanced Cluster Security already installed. Let's make sure everything's working - click the commands below:

[source,bash,role="execute"]
----
oc whoami
----

You should see your admin user.

[source,bash,role="execute"]
----
oc get nodes
----

Three nodes, all `Ready`.

Now confirm RHACS is up:

[source,bash,role="execute"]
----
oc get pods -n stackrox
----

You should see Central, Scanner, and Sensor pods in `Running` state. That's the platform that will scan your workloads in the next module.

== About This Lab

Shipping containers fast is easy. Knowing what's inside them is not.

A typical cluster runs images pulled from registries nobody audited, built from base layers nobody tracked, with permissions nobody reviewed. When a CVE like Log4Shell lands, the question isn't "are we vulnerable?" - it's "where, and how fast can we tell?"

This lab answers that question hands-on. You'll deploy a set of deliberately insecure applications, then use Red Hat Advanced Cluster Security to find what's wrong with them - running compliance scans against real benchmarks, inspecting policy violations, and seeing exactly which workloads break which rules.

=== Your Lab Interface

Your lab runs in a split-panel interface with the following panels:

* **Left panel** - Instructions (what you're reading now)
* **Right panel** - Tabbed workspace with your cluster tools
* **Draggable divider** - Drag the border between panels to resize

image::showroom-tabs.png[Showroom interface showing tabs for OCP Console, Terminal, and RHACS, link=self, window=blank]

[cols="1,3"]
|===
|Tab |What it is

|**OCP Console**
|The OpenShift web console - cluster management, monitoring dashboards, and troubleshooting.

|**Terminal**
|A web-based terminal pre-connected to your cluster. Run `oc` commands directly - no local setup needed.

|**RHACS**
|Red Hat Advanced Cluster Security - vulnerability scanning, compliance, and runtime security. This is where you'll spend most of the lab.
|===

TIP: Highlighted command blocks are **clickable** - they switch to the Terminal tab and execute automatically.

=== What You'll Do

[cols="1,3"]
|===
|Area |What you'll do

|**Deploy insecure workloads**
|Apply a set of deliberately vulnerable applications - emojivoto, Apache Struts, DVWA, and Log4Shell - to give RHACS something real to find

|**Compliance scanning**
|Create a scan schedule, run it against the Essential Eight (E8) benchmark, and read the results per cluster and per check

|**Policy violations**
|Inspect what RHACS flagged, drill into a violation, and understand which policy fired and why
|===
